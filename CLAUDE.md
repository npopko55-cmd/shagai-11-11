# Распродажа 11.11 «Шагай Дома»

Боевая страница: https://walk-walk.ru/rasprodazha-11-11 (Тильда, проект 8060962, страница 374384309).
Черновик и источник вёрстки: https://npopko55-cmd.github.io/shagai-11-11/v5/ (GitHub Pages, ветка main).

## Сборка

- `python3 build_v5.py` собирает `v5/index.html`. Тексты и цены лежат в `v4_data_snapshot.py`, абонементы в `CLUBS` внутри `build_v5.py`.
- `python3 tilda/build_tilda_vibe.py` собирает 7 блоков для Тильды в `tilda/tilda-vibe/` из `v5/`. Сборка падает, если в блоках осталась ссылка на github или `assets/`.

## Проверка (без неё работу не сдавать)

- Кнопки и формы: `node tools/v5_check.mjs <URL> 390 844` и `node tools/v5_check.mjs <URL> 1440 900`.
  Ждём: сообщение 7 из 7, формы 6 из 6, прокрутки вбок нет. Формы GetCourse только открываются, ничего не заполняется.
- Тильда после публикации: `python3 tools/tilda_compare.py`. Ждём «СОВПАДАЕТ» у всех 7 блоков и 0 ссылок на github.
- Ширины: открыть `_test_audit_v5.html` через `python3 -m http.server`, 19 ширин от 320 до 1920.
- Скрин страницы целиком: `node tools/full_shot.mjs <URL> 390 844 out.png`.
- После пуша сверить хеши файлов на Pages с локальными (`shasum`).

## Выкладка в Тильду

1. Собрать блоки, закоммитить.
2. Перед записью прочитать текущий код блока (`edit_record`) и сравнить с прошлой версией файла в git: блок могли править руками.
3. Записать код целиком (`update_record`, `only_field="code"`), опубликовать (`publish_page`), запустить `tools/tilda_compare.py`.
4. Неразрывные пробелы в JSON передавать как `\u00a0`, иначе они превращаются в обычные.
5. Картинки только с `static.tildacdn.com` (адреса в `tilda/tilda-assets.json`). Ссылок на GitHub в Тильде быть не должно.

## Чего не трогать

- Корень репозитория (v3), `v2/`, `v4/`.
- `id` и `sid` виджетов GetCourse. Виджеты не выдумывать: у кнопки без виджета открывается сообщение с телефоном.
- Другие страницы Тильды и настройки её проекта.
- Слова «пак», «набор», «год» на странице запрещены (правка Марии), продукты называются «программы» и «абонементы».
- Репозиторий публичный: без секретов, без папок с отзывами.

Над страницей одновременно работают несколько сессий. Перед правкой: `git fetch`, `git status`, `git log`. Коммитить только свои файлы.
